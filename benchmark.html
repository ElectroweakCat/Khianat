Why this page exists

The Elo number on the About page has always been a guess, made from the list of features the engine has. That is not worth much. This page collects what can actually be measured, together with everything those measurements cannot tell us.

All tests run offline, on my own machine, with a fixed search depth. Fixed depth matters: the difficulty levels on the Play page are defined by thinking time, so a fast computer would look stronger than a phone. Depth is the same everywhere, which makes runs comparable between machines and between engine versions. The opening randomisation is switched off while measuring, so a run can be repeated with the same result.

The tests

Tactics. Puzzles from the Lichess database, which is public domain and, more importantly, comes with a rating for every puzzle. Sorted into rating bands, the solve rate shows where Khianat starts to fail. The rating at which it solves half the puzzles is the closest thing to a measured number this project has.

Forced mates. Mate in two and mate in three. Pass or fail, no partial credit.

Endgame technique. Can the engine actually finish? Queen and king against a bare king, rook and king, two rooks, escorting a pawn home. It plays against a random defence and has to mate within a move limit.

Move quality. Khianat plays against itself and Stockfish judges every move: how many centipawns did it give away compared to the best move? This is the same measure used to analyse human games.

Match play. Games against a rating limited Stockfish, with colours alternating. The score is converted into a rating difference.

Stockfish is only used offline. It is licensed under the GPL and is not part of this website, so nothing here makes the site bigger or slower.

What the numbers do not say

Solving puzzles is not the same as playing well. A puzzle announces that something is there to be found; a real game does not. Khianat could be sharp tactically and still drift in quiet positions, and the evaluation function it uses says nothing about pawn structure or king safety.

Stockfish's rating limiter runs on its own scale. It is not a human rating, and a score against it does not translate cleanly into one. Even a forty game match leaves an uncertainty of well over a hundred points, which is why any Elo figure here comes with its confidence interval attached.

So: the tactics rating is measured, the match results are measured, and every Elo number derived from them is an orientation. Khianat has never played a rated game against a human.
